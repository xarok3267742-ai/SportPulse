# Адаптивные опции

Короткий набор действий должен быть виден целиком без жеста, о котором пользователь не знает. Поэтому виды спорта, периоды, метки события, типы проверки, временные срезы и шаблоны рынка используют `AdaptiveWrapLayout` вместо горизонтальной прокрутки.

## Правила

1. Контейнер измеряет доступную ширину и фактический размер каждого дочернего элемента.
2. Если следующий элемент не помещается, он целиком переходит на новую строку.
3. Текст не уменьшается, не получает многоточие и не обрезается по правой границе.
4. Высота контейнера растёт вместе с числом строк и системным масштабом шрифта.
5. Выбранный пункт сохраняет текстовый и цветовой статус, `isSelected` и отдельное accessibility-описание.
6. Нажатие получает нативную ripple-обратную связь, а минимальная высота интерактивного элемента остаётся не меньше 40 dp.

Матч-центр не показывает пустые категории: в строку попадают только виды спорта текущего каталога, а команда «Сохранённые» появляется только при наличии сохранённого события в этом каталоге. Смена источника автоматически возвращает недоступный старый фильтр к значению «Все».

Горизонтальная прокрутка допустима только для длинной навигационной ленты, где текущий пункт автоматически приводится в видимую область. Она не используется как способ спрятать часть короткого набора решений.

## Проверка

`TextLayoutInstrumentationTest.adaptiveOptionGroupsKeepEveryChildInsideTheirWidth` проходит Матч-центр, Инструменты, Штаб и Чек-листы. Для каждой группы он проверяет ненулевой измеренный размер и положение всех дочерних элементов внутри левой, правой и нижней границ контейнера. Один и тот же тест выполняется при системном масштабе шрифта 100% и 200%.
