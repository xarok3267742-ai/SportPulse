# Контрракурс

«Контрракурс» — локальная пятифакторная проверка альтернативной версии спортивного разбора. Он снижает риск подтверждающего уклона: пользователь отдельно фиксирует, искал ли существенные факты против собственной исходной оценки.

Контур не предсказывает результат события, не проверяет факты через интернет и никогда не повышает полноту данных. Он отвечает только на вопрос: какой вывод допустим при текущей полноте контрпроверки.

## Состояния фактора

| Состояние | Смысл |
| --- | --- |
| Не проверено | Альтернативную трактовку фактора еще не искали |
| Проверено | Существенных фактов против исходной версии не найдено |
| Есть спор | Независимые факты допускают разные трактовки |
| Контрфакт | Найден факт, который ломает исходную версию |

Все состояния задаются пользователем вручную. «Проверено» не является внешней сертификацией истинности.

## Потолок решения

Сначала считаются пять доказательно ограниченных значений после «Антиэхо» и проверки свежести. Их числовая готовность не меняется. Затем «Контрракурс» задает максимальный вывод:

| Условие | Максимальный вывод |
| --- | --- |
| Есть хотя бы один контрфакт | Пропустить |
| Проверено меньше трех факторов | Пропустить |
| Есть спорный фактор | Наблюдать |
| Проверено три или четыре фактора | Наблюдать |
| Проверены все пять, споров и контрфактов нет | Факты сверены |

Фактический статус не может быть повышен до этого потолка. Например, полностью выполненная контрпроверка не превращает слабые данные в готовые.

Кнопка сохранения вывода выше потолка блокируется. Если после сохранения решения появляется спор или контрфакт, «Стоп-контракт» срабатывает с отдельной причиной `COUNTERVIEW_LIMIT`.

## Следующая проверка

Для каждого открытого фактора движок временно обнуляет только его доказательно поддержанное значение и повторно считает готовность. Следующим выбирается фактор:

1. с наибольшим падением готовности;
2. затем с большим поддержанным значением;
3. затем по стабильному порядку пяти факторов.

Контрсценарий не сохраняется и не изменяет пользовательские шкалы.

## Контрольная метка

SHA-256 считается от UTF-8 строки:

```text
sport-pulse-counter-view-v1|<оценки>|<эффективные уровни подтверждения>|<пять состояний Контрракурса>
```

На экране и в PNG-паспорте показываются первые восемь символов метки. Это локальный маркер целостности, а не электронная подпись.

## Снимок решения и миграция

Новый снимок решения использует формат версии 2 и включает пять состояний «Контрракурса» в собственную SHA-256-пломбу.

Снимки версии 1 продолжают читаться. При миграции им назначается состояние «Не проверено» по всем факторам: приложение не выдумывает ранее не выполненную контрпроверку. Новый снимок нужен для нового вывода.

## Ограничения

- Контур не доказывает, что пользователь действительно изучил альтернативные источники.
- Он не определяет направление ставки, вероятность, коэффициент или финансовый результат.
- Спор и контрфакт должны опираться на спортивные факты, а не на движение линии или чужое мнение.
- «Контрракурс» дополняет независимость источников, но не заменяет «Антиэхо».
