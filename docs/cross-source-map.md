# Кросс-эхо

«Кросс-эхо» — вычисляемая карта происхождений внутри «Реестра фактов». Обычный «Антиэхо» проверяет связь двух источников одного фактора; новая карта отвечает на другой вопрос: не поддерживает ли один и тот же домен или один и тот же названный источник сразу несколько факторов.

## Нормализация

В карту попадают только источники валидных «Факт-квитанций». Для URL используется домен без `www`; путь и параметры не создают новое происхождение. Для названий применяется Unicode-нормализация, нижний регистр и удаление пробелов и знаков. Поэтому две ссылки одного сайта считаются одним происхождением, как и два по-разному оформленных одинаковых названия.

Повтор первичного и второго источника внутри одного фактора не является межфакторным эхом. Статус `REUSED` появляется только тогда, когда одно нормализованное происхождение встречается минимум в двух разных факторах.

## Состояния

| Состояние | Условие |
| --- | --- |
| `EMPTY` | Валидных квитанций с источниками нет |
| `BUILDING` | Источники записаны только для одного фактора |
| `DISTRIBUTED` | Покрыто минимум два фактора, межфакторных повторов нет |
| `REUSED` | Найдено происхождение, общее минимум для двух факторов |

Повтор показывает общую зависимость, но не доказывает ложность публикации, редакционную связь или сговор. Поэтому карта fail-neutral: она не меняет оценку фактора, кворум, состояние реестра или журнал решения.

## Следующий шаг

При `REUSED` карта выбирает одно происхождение с максимальным числом затронутых факторов, затем с максимальным числом упоминаний и стабильным лексикографическим порядком. Фактор для разнообразия выбирается по меньшему числу уникальных происхождений, более проблемному состоянию строки реестра и порядку `форма → состав → нагрузка → контекст → источники`.

Команда открывает существующую «Факт-квитанцию» этого фактора. Пользователь сам решает, заменить ли источник, добавить второй или только уточнить связь.

## Целостность и хранение

SHA-256-метка карты связывает версию алгоритма, событие, нормализованные происхождения, число упоминаний и упорядоченный набор факторов каждого происхождения. Карта не сохраняется отдельно, не выполняет сетевые запросы и не создаёт историю просмотра.
