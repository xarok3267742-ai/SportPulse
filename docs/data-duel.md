# Дуэль данных

«Дуэль данных» сравнивает качество текущих локальных данных двух спортивных событий. Она не сравнивает силу команд, не использует коэффициенты и не прогнозирует исход.

## Порядок расчета

Для каждой стороны приложение:

1. применяет аудит «Антиэхо» к заявленным уровням подтверждения;
2. применяет срок жизни каждого фактора;
3. ограничивает оценки свежими эффективными уровнями подтверждения;
4. рассчитывает готовность и шум;
5. рассчитывает отдельный потолок «Контрракурса».

Таким образом, заявленный кворум с неизвестным происхождением не может выиграть дорожку свежего кворума.

## Шесть дорожек

| Дорожка | Значение | Лучше |
| --- | --- | --- |
| Готовность | подтвержденная готовность от 0 до 100 | больше |
| Чистота сигнала | `100 - шум` | больше |
| Свежий кворум | количество факторов с эффективным уровнем `QUORUM` | больше |
| Независимость | количество подтвержденных факторов с аудитом `INDEPENDENT` | больше |
| Контрпроверка | количество факторов не в состоянии `UNCHECKED` | больше |
| Запас срока | минимум минут до следующего снижения подтверждения | больше |

Пять первых дорожек получают преимущество при разнице минимум в одну единицу. Для запаса срока разница меньше пяти минут считается ничьей, чтобы задержка открытия экранов не создавала ложное преимущество.

Каждая дорожка имеет одинаковый вес. Итог `слева : справа` является только количеством выигранных дорожек; ничьи показываются отдельно. Скрытого общего рейтинга нет.

## Потолок решения

Потолок «Контрракурса» выводится отдельно для каждой стороны и не входит в счет дорожек. Поэтому полностью проверенный контрфакт не может быть замаскирован высоким покрытием остальных данных.

## Контрольная метка

Каждый профиль получает SHA-256 от:

```text
sport-pulse-data-duel-profile-v1
|минута_расчета
|event_id
|оценки
|заявленные_уровни
|аудит_источников
|времена_проверки
|контрпроверки
|эффективные_уровни
|запас_срока
```

Итоговая метка использует версию `sport-pulse-data-duel-v1`, минуту расчета, две полные метки профилей, значения шести дорожек и сторону преимущества каждой дорожки. Перестановка сторон меняет метку.

Это локальная контрольная метка воспроизводимости, а не электронная подпись и не доверенная временная метка.

## Локальное состояние

Приложение сохраняет только выбранное правое событие и обычные локальные данные каждого события. Открытие профиля впервые запускает его стандартный локальный срок жизни подтверждений. Отдельный итог или скрытый рейтинг «Дуэли данных» не сохраняется.

## Ограничения

- Сравнение корректно только настолько, насколько корректны введенные оценки и подтверждения обеих сторон.
- Большее число выигранных дорожек не означает более выгодное событие.
- Ничья не означает равенство команд или вероятностей.
- Для реального использования события и составы должны поступать из лицензированного источника.
