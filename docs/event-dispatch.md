# Диспетчер событий

«Диспетчер событий» переносит объяснимую очередь «Штаба проверки» с одного события на всю текущую область ленты. Он отвечает только на вопрос «какое событие требует проверки раньше» и не сравнивает команды, коэффициенты или вероятность исхода.

## Область

Область диспетчера всегда совпадает с активным фильтром ленты:

- все события;
- выбранный вид спорта;
- только сохранённые события.

После импорта Event Pack используются события активного пакета. Истёкший пакет автоматически заменяется демо-каталогом по общим правилам приложения.

## Read-only снимок

Для каждого события лента читает оценки, заявленные подтверждения, аудит источников, «Контрракурс», снимок решения и защёлкнутое нарушение. Временная шкала читается методом `evidenceTimelinePreview`:

- существующие отметки используются без изменения;
- отсутствующие отметки подставляются текущим моментом только для расчёта экрана;
- просмотр ленты не создаёт отметки в `SharedPreferences` и не делает данные «свежее»;
- настоящая история начинается при открытии анализа или явном изменении подтверждения.

Событие без сохранённых временных отметок помечается «Без истории».

## Расчёт события

Каждый элемент области проходит полный `VerificationCommandEngine`. Диспетчер получает готовую первую задачу и её опубликованный уровень:

1. `СТОП`;
2. `РЕМОНТ`;
3. `СВЕЖЕСТЬ`;
4. `ПРОВЕРКА`;
5. `МАРШРУТ`;
6. `КОНТРОЛЬ`.

Диспетчер не пересчитывает внутренний вес задачи и не добавляет общий балл события.

## Межсобытийный порядок

События сортируются лексикографически:

1. уровень первой задачи;
2. ближайший известный дедлайн первой задачи;
3. опубликованный тип причины;
4. сохранённое событие раньше несохранённого;
5. событие с начатой историей раньше события без истории;
6. исходный порядок активного каталога;
7. стабильный ID события.

Каждый предыдущий критерий целиком важнее следующего. Закладка никогда не поднимает событие выше более серьёзной причины или раннего дедлайна.

## Экран

Четыре полосы показывают точное количество событий в категориях:

- `СТОП`;
- `ВНИМАНИЕ` — есть `РЕМОНТ` или `СВЕЖЕСТЬ`;
- `В РАБОТЕ` — есть `ПРОВЕРКА` или `МАРШРУТ`;
- `СТАБИЛЬНО` — остаётся только контроль срока.

Показываются первые три события и полное количество в области. Нажатие открывает выбранное событие в «Пульсе» и ничего не подтверждает автоматически.

## Контрольная метка

SHA-256 версии `sport-pulse-event-dispatch-v1` связывает для всей упорядоченной области:

- ID и исходный порядок события;
- состояние закладки и наличие истории;
- полную метку его «Штаба проверки»;
- метку первой задачи.

Скрытые за первыми тремя строками события также входят в метку. Она доказывает воспроизводимость локальной сортировки, но не является электронной подписью и не подтверждает истинность исходных данных.

## Ограничения

Диспетчер не сохраняется отдельно, не использует сеть, фоновые задачи, уведомления или разрешения Android. Он не знает счёт, коэффициенты, финансовый результат или предпочтительную команду. Для актуальных спортивных фактов требуется лицензированный поставщик и официальная сверка.
