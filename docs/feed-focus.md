# Матч-центр

## Задача

«Матч-центр» — стартовый режим раздела «Матчи». Он не добавляет прогноз и не ранжирует команды по силе. Задача экрана — сразу показать ближайшие события, их время, турнир и одну первую проверку. Импорт, радары и исследовательские панели остаются в режиме «Инструменты».

## Выбор события

Сначала события делятся по фактическому состоянию API:

1. матч идёт;
2. матч ещё не начался;
3. матч отложен или приостановлен;
4. состояние не удалось классифицировать;
5. матч завершён, отменён или закрыт решением провайдера.

Если есть хотя бы одно незавершённое событие, терминальные события не участвуют в выборе главного шага. Они остаются в каталоге и перемещаются ниже. Если фильтр содержит только терминальные события, режим всё равно остаётся работоспособным и выбирает первое из них.

## Расчётное окно

Для выбора первой проверки матч-центр запускает существующую детерминированную очередь не для всех 60 событий, а для 12 ближайших незавершённых событий. Сохранённые пользователем события добавляются в окно независимо от позиции, общий предел — 16.

Внутри окна сохраняются строгие правила «Диспетчера событий»: стоп-причина, восстановление повреждённых данных, срок свежести, открытая контрпроверка, маршрут, закладка и порядок каталога. На экране явно показаны размер окна, общий размер выбранной области и короткая SHA-256-метка очереди.

## Интерфейс

- «Матч-центр» является безопасным режимом по умолчанию и сохраняется локально;
- фирменный hero сокращён на обычном шрифте, чтобы первая строка расписания была видна без прокрутки;
- четыре строки показывают статус, матч, региональное время, турнир, регион, закладку и переход в анализ;
- строка с первой проверкой всегда попадает в видимую четвёрку; если она находится дальше, она замещает четвёртую, но не меняет первые три;
- остальные строки открываются явной командой «Показать ещё»;
- компактный блок «С чего начать» объясняет причину, срок и ведёт в короткий анализ;
- «Инструменты» восстанавливают полный прежний экран, включая импорт, обновления API и исследовательские панели.

Ни коэффициенты, ни вероятность исхода, ни финансовый результат в правила выбора не входят.

## Проверка

`MatchCenterPolicyTest` проверяет порядок, лимит, включение приоритетного события и fail-fast на повторяющихся ID. `TextLayoutInstrumentationTest` доказывает, что при штатном шрифте первый матч виден без прокрутки, а при 150% и 200% все тексты остаются без обрезания и многоточий.
