# Линза рынков

«Линза рынков» связывает справочник спортивных рынков с текущей пятифакторной картой события. Она отвечает только на вопрос о достаточности проверяемых данных. Результат не является вероятностью, прогнозом исхода или рекомендацией ставки.

## Входные данные

Для каждого события используются пять факторов:

1. форма;
2. состав;
3. нагрузка;
4. контекст;
5. источники.

Сначала к пользовательской оценке применяются уже существующие ограничения доказательств и свежести:

- нет подтверждения: не более `25`;
- один источник: не более `60`;
- кворум двух независимых источников: не более `100`;
- истекшее подтверждение автоматически теряет уровень.

Перед этим «Антиэхо» проверяет происхождение заявленного кворума. Статус `2+` допускается в матрицу только после ручной отметки «Независимы». Непроверенный кворум и два сообщения из одной первичной цепочки превращаются в один источник, а расхождение — в неподтвержденный фактор. Поэтому «Линза рынков» не может обойти аудит происхождения.

Матрица показывает именно полученное эффективное значение, а не исходное положение шкалы.

Цвет ячейки отражает полное условие покрытия: красный означает значение ниже `40`, янтарный — значение ниже `60` или критический фактор без свежего кворума, зеленый — выполненное условие. Рамка выделяет критические факторы.

## Применимость

Каждый шаблон рынка имеет фиксированный набор видов спорта, обязательных факторов и критических факторов:

| Шаблон | Виды спорта | Критические факторы |
| --- | --- | --- |
| 1X2 | футбол, хоккей | состав, источники |
| Фора | все распознанные и неизвестные | форма, состав, источники |
| Тотал | все распознанные и неизвестные | нагрузка, контекст, источники |
| Обе забьют | футбол | состав, источники |
| Индивидуальный тотал | футбол, хоккей, баскетбол, теннис, киберспорт | состав, источники |
| Период / сет / раунд | футбол, хоккей, баскетбол, теннис, единоборства, киберспорт | состав, нагрузка, источники |

Если шаблон не применяется к виду спорта, он получает статус `НЕ ПРИМЕНЯЕТСЯ` и не участвует в счетчиках покрытия. Регламент конкретного турнира всегда имеет приоритет над встроенной классификацией.

## Статусы

Статус рассчитывается детерминированно:

- `ДАННЫЕ ЗАКРЫТЫ`: хотя бы один критический фактор ниже `40`;
- `НУЖНА ПРОВЕРКА`: стоп-фактора нет, но не все обязательные факторы достигли `60` или критическому фактору не хватает свежего кворума;
- `ДАННЫЕ ПОКРЫТЫ`: каждый обязательный фактор не ниже `60`, а каждый критический фактор имеет свежий кворум;
- `НЕ ПРИМЕНЯЕТСЯ`: шаблон отключен для текущего вида спорта.

Высокие значения некритических факторов не компенсируют критический фактор ниже стоп-порога.

## Следующая проверка

Для каждого применимого шаблона выбирается одно следующее действие в стабильном порядке:

1. самый слабый критический блокер;
2. критический фактор без кворума;
3. обязательный фактор с наибольшим разрывом до `60`;
4. критический кворум с ближайшей потерей свежести;
5. ближайшее плановое обновление критического фактора.

Кнопка открывает тот же фактор на экране «Пульс». Выбор рынка не меняет оценки, подтверждения или журнал решения.

## Фактор-рычаг

«Фактор-рычаг» ищет одну проверку с максимальным доказательным эффектом сразу для всех применимых шаблонов. Для каждого из пяти факторов приложение создает только в памяти отдельный контрсценарий:

1. исходная оценка фактора поднимается не выше необходимого минимума: `max(текущее значение, 60)`;
2. контрсценарий предполагает свежий независимый кворум;
3. время проверки устанавливается в текущий момент;
4. «Линза рынков» полностью пересчитывается;
5. результат сравнивается с неизмененной исходной матрицей.

Контрсценарий не записывается в локальное состояние и не меняет шкалы, подтверждения, журнал решения или стоп-контракт.

Для каждого фактора считаются:

- сумма переходов по шкале `ДАННЫЕ ЗАКРЫТЫ → НУЖНА ПРОВЕРКА → ДАННЫЕ ПОКРЫТЫ`;
- число шаблонов с изменившимся статусом;
- прирост выполненных условий покрытия;
- общий охват шаблонов;
- число шаблонов, где фактор является критическим.

Победитель выбирается лексикографически в этом порядке. При полном равенстве используется стабильный порядок пяти факторов, поэтому одинаковый ввод всегда дает одинаковый результат.

Если ни один контрсценарий не улучшает матрицу, все применимые шаблоны уже покрыты. Тогда включается режим обслуживания: выбирается критический фактор с ближайшей потерей свежести, затем с наибольшим охватом рынков и, при равенстве, по стабильному порядку факторов.

Это приоритет сбора и обновления фактов, а не приоритет рынка. Условие `60 + свежий кворум` описывает проверяемую границу покрытия и не утверждает, что новые сведения действительно подтвердят указанное значение.

Контрсценарий не подтверждает независимость автоматически. Для достижения показанного состояния пользователь должен собрать заявленный кворум и отдельно пройти аудит Антиэхо в «Пульсе».

## Ограничения

- Матрица не использует коэффициенты букмекеров.
- Матрица не считает вероятность, ожидаемую доходность или размер ставки.
- Статус `ДАННЫЕ ПОКРЫТЫ` означает полноту текущих входных данных, а не преимущество рынка.
- Приложение не получает фоновые обновления: свежесть пересчитывается при открытии анализа.
- Реальные события, составы и регламенты требуют лицензированного поставщика и официальной сверки.
