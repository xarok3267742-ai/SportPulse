# Чек-листы рынков

Экран связывает справочник типов спортивных рынков с пятью группами фактов выбранного события. Он отвечает только на вопрос: какие сведения уже имеют источник и что необходимо перепроверить. Результат не является вероятностью, прогнозом, расчетом ожидаемой выгоды или рекомендацией ставки.

## Входные данные

Для каждого события используются пять факторов:

1. форма;
2. состав;
3. нагрузка;
4. контекст;
5. источники.

Каждый фактор имеет один из трех доказательных уровней:

- `0` — подтвержденного источника нет;
- `1` — есть один источник;
- `2` — есть два независимо сверенных источника.

«Антиэхо» отдельно проверяет происхождение заявленного второго источника. Два сообщения из одной первичной цепочки считаются одним источником, а зафиксированное расхождение возвращает фактор в неподтвержденное состояние. Истекшее подтверждение также автоматически теряет уровень.

Матрица показывает количество действующих источников `0/1/2`. Рамка выделяет критические факторы. Пользовательская шкала `0–100` в статусе чек-листа не участвует.

## Применимость

Каждый шаблон имеет фиксированный набор видов спорта, обязательных факторов и критических факторов:

| Шаблон | Виды спорта | Критические факторы |
| --- | --- | --- |
| 1X2 | футбол, хоккей | состав, источники |
| Фора | все распознанные и неизвестные | форма, состав, источники |
| Тотал | все распознанные и неизвестные | нагрузка, контекст, источники |
| Обе забьют | футбол | состав, источники |
| Индивидуальный тотал | футбол, хоккей, баскетбол, теннис, киберспорт | состав, источники |
| Период / сет / раунд | футбол, хоккей, баскетбол, теннис, единоборства, киберспорт | состав, нагрузка, источники |

Если шаблон не применяется к виду спорта, он получает статус `НЕ ПРИМЕНЯЕТСЯ` и не участвует в счетчиках. Регламент конкретного турнира всегда имеет приоритет над встроенной классификацией.

## Статусы

Статус рассчитывается детерминированно:

- `ЕСТЬ ПРОБЕЛЫ`: хотя бы один критический фактор не имеет источника;
- `НУЖНА СВЕРКА`: критического пробела нет, но обязательному фактору не хватает источника либо критическому фактору не хватает свежей независимой сверки;
- `ЧЕК-ЛИСТ ГОТОВ`: каждый обязательный фактор имеет источник, а каждый критический фактор имеет свежую независимую сверку;
- `НЕ ПРИМЕНЯЕТСЯ`: шаблон отключен для текущего вида спорта.

Высокое значение ручной шкалы не компенсирует отсутствие источника. Низкое значение ручной шкалы не закрывает чек-лист, если доказательные условия выполнены.

## Следующая проверка

Для каждого применимого шаблона выбирается одно следующее действие в стабильном порядке:

1. критический фактор без источника;
2. критический фактор без независимой сверки;
3. обязательный фактор без источника;
4. критический фактор с ближайшей потерей свежести;
5. ближайшее плановое обновление обязательного фактора.

Кнопка открывает тот же фактор на экране «Пульс». Выбор шаблона не меняет оценки, подтверждения или журнал решения.

Служебный планировщик может сравнить пять возможных проверок и выбрать одну с максимальным доказательным эффектом. Контрсценарий существует только в памяти, не повышает ручной балл, не записывает кворум и не показывается как прогноз.

## Ограничения

- Чек-листы не используют коэффициенты букмекеров.
- Чек-листы не считают вероятность, ожидаемую доходность или размер ставки.
- Статус `ЧЕК-ЛИСТ ГОТОВ` означает только выполнение правил сбора источников.
- Приложение не получает фоновые обновления: свежесть пересчитывается при открытии анализа.
- Реальные события, составы и регламенты требуют лицензированного поставщика и официальной сверки.
