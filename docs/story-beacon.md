# Маяк события

«Маяк события» — read-only временная карта ближайших смысловых изменений одного спортивного события. Он не прогнозирует исход, не показывает коэффициенты и не создает давление обратным отсчетом. Его задача — объяснить, когда текущий сюжет или качество данных действительно могут перейти в другое состояние.

## Опорные моменты

Маяк использует не больше пяти моментов и не больше одной ближайшей точки каждого типа:

| Тип | Источник | Значение |
| --- | --- | --- |
| Действие сейчас | текущее действие «Сюжета события» | проверка источника, факта, плана, решения или разбора уже доступна |
| Окно проверки | ближайший будущий слот «Предстартового протокола» | с этого момента повторная проверка сохранит подтверждение до старта |
| Срок факта | ближайший `firstTransitionAt` «Эстафеты фактов» | без нового подтверждения эффективный уровень снизится |
| Старт | проверяемое время текущей афиши | предстартовые действия закрываются |
| Разбор | старт плюс четыре часа | ретроспектива может открыться после отдельной проверки завершения события |

Если несколько факторов теряют свежесть в один момент, они объединяются в одну точку и сортируются в порядке пяти факторов. Несколько календарных слотов не превращаются в длинную очередь: Маяк показывает только ближайший будущий слот, а полный план остается в «Лаборатории».

## Строгий отбор

До старта моменты располагаются так:

1. действие сейчас, если оно существует;
2. ближайшие временные точки по возрастанию времени;
3. при одинаковом времени — окно проверки раньше срока факта, затем старт и разбор.

Временно́й список содержит максимум четыре будущие точки: ближайшее окно проверки, ближайшее доказуемое снижение свежести, старт и разбор. Вместе с действием сейчас получается максимум пять узлов.

После старта прежние предстартовые окна не показываются. До границы разбора остается только момент открытия ретроспективы. После нее Маяк показывает действие «Открыть разбор», завершенный маршрут или честное отсутствие следующей точки.

## Защита от ложной точности

Read-only `evidenceTimelinePreview()` подставляет текущее время только для вычисления экрана и ничего не записывает. Маяк не использует такую подстановку как доказанный абсолютный срок факта. Точка «Срок факта» появляется только тогда, когда у конкретного фактора уже есть сохраненная локальная отметка проверки.

Без точного `startAt` или демонстрационного расписания Маяк не придумывает календарь. Для демо используется ближайшее еженедельное вхождение по правилам «Сюжета события». Указанный старт не подтверждает перенос, отмену или фактическое начало матча.

Граница разбора всегда равна `startAt + 4 часа`. Это консервативная защита порядка действий, а не утверждение о финальном свистке, дополнительном времени или официальном результате.

## Состояния

| Состояние | Условие |
| --- | --- |
| `NO_TIMELINE` | проверяемого старта нет |
| `ACTION_NOW` | до старта доступно следующее действие |
| `WATCHING` | действия сейчас нет, впереди временная точка |
| `EVENT_ACTIVE` | старт прошел, минимальное окно события еще идет |
| `REVIEW_DUE` | граница разбора пройдена и ретроспектива доступна |
| `COMPLETE` | связанная ретроспектива завершена |
| `INCOMPLETE` | хронология закончилась без доступной следующей главы |

Состояния не являются рейтингом события и не складываются в скрытый балл.

## Контрольная метка

SHA-256 версии `sport-pulse-story-beacon-v1` связывает:

- ID события и полную метку «Сюжета события»;
- минуту вычисления и состояние Маяка;
- тип и минуту каждой опорной точки;
- действие сейчас и выбранный фактор;
- сгруппированные факторы окна проверки или снижения свежести.

Поля кодируются с длиной перед значением, поэтому разделители внутри ID не создают неоднозначность. Текст интерфейса не входит в метку. Выбранная зона форматирует UTC-моменты на экране, а ее уже существующее влияние на календарный контур может быть транзитивно связано через полную метку «Сюжета события». Метка подтверждает детерминированность локального расчета, но не является электронной подписью и не доказывает внешние спортивные факты.

## Приватность и ограничения

- просмотр Маяка ничего не записывает;
- уведомления, будильники, фоновые сервисы, сеть и геолокация не используются;
- Маяк не расходует «Бюджет внимания» в режиме «Сюжет»;
- отдельная история Маяка и профиль возвращаемости не создаются;
- временные точки не экспортируются автоматически;
- полная проверка и изменение данных доступны только после явного перехода в «Лабораторию».

Для production-сценария необходимы лицензированная афиша, аутентифицированные обновления, официальные статусы переноса и завершения события. Без них Маяк честно описывает только текущую локальную версию данных.
