# «Кадр возвращения»

«Кадр возвращения» превращает уже открытую «Капсулу возврата» в переносимый PNG `1080 × 1350`. Он показывает исходную точку, состояние личного вопроса `тогда → сейчас`, честный итог возвращения и две короткие SHA-256-метки. Это артефакт одного завершенного цикла внимания, а не прогноз, ставка, подтверждение внешнего результата или полный аналитический паспорт.

## Граница создания

Действие доступно только после окончания глобальной паузы и только для валидной капсулы в любом состоянии, кроме `SEALED`. Нажатие не использует уже показанный результат как доверенный снимок. Непосредственно перед экспортом приложение:

1. повторно читает капсулу из закрытого хранилища;
2. отклоняет отсутствующую или поврежденную пломбу;
3. заново вычисляет полную read-only «Карту нитей» на одном значении `now`;
4. повторно оценивает состояние капсулы;
5. создает минимальный неизменяемый кадр;
6. только после этого передает кадр фоновому PNG-рендеру.

Если пауза снова активна, капсула еще запечатана или контракт времени больше не согласуется, экспорт прекращается fail-closed и экран пересчитывается.

## Минимальный снимок

`StoryReturnFrame` не удерживает `StoryReturnCapsuleResult`, `StoryThreadMapResult`, строку карты или полный результат нити. В кадр копируются только:

- ID и афиша исходного события;
- выбранная глава вопроса;
- время пломбы и фактическая граница паузы;
- вид, время и факторы исходной абсолютной точки;
- состояния строки карты `тогда` и `сейчас`;
- одно из девяти открытых состояний возвращения;
- новая абсолютная точка только для `POINT_MOVED`;
- полная метка повторно вычисленного результата;
- выбранная IANA-зона и время экспорта;
- отдельная SHA-256-пломба кадра.

Оценки пяти факторов, коэффициенты, рынки, решение, ответы ретроспективы, другие события карты и история посещений не экспортируются.

## Честные состояния

| Состояние капсулы | Представление в кадре |
| --- | --- |
| `SEALED` | Экспорт запрещен |
| `LIMIT_REACHED` | Сейчас: «не вскрыто»; исходная точка явно остается впереди |
| `UNCHANGED` | Точка наступила, локальная версия не изменилась |
| `POINT_MOVED` | Показана одна новая точка того же вида с более поздним временем |
| `CHANGED` | Зафиксирован смысловой переход открытой нити |
| `RESOLVED` | Локальный вопрос получил завершенное состояние |
| `MISSED` | Предстартовый момент прошел без завершения вопроса |
| `DETACHED` | Нить сохранена, события больше нет в каталоге |
| `MISSING` | Текущая нить отсутствует, исходная пломба остается читаемой |
| `CURRENT_TAMPERED` | Текущая запись явно показана как не прошедшая проверку |

`LIMIT_REACHED` допустим только между фактической 24-часовой границей паузы и более дальней исходной точкой. Для остальных кадров время экспорта не может быть раньше исходной точки. Так артефакт не может назвать окончание суточной паузы достижением более далекого момента.

## Пломба кадра

SHA-256 версии `sport-pulse-story-return-frame-v1` вычисляется по канонической строке с явной длиной каждого поля. Она связывает:

- событие, главу и временные границы;
- исходную и при необходимости новую точку;
- состояния `тогда → сейчас` и классификацию итога;
- полную SHA-256-метку результата капсулы;
- выбранную региональную зону;
- точное время создания PNG.

Изменение любого отображаемого смыслового поля, зоны или времени экспорта меняет пломбу. В подвале PNG выводятся первые восемь символов метки кадра и метки результата. SHA-256 подтверждает целостность локального расчета, но не является электронной подписью, серверским штампом времени или доказательством внешнего спортивного факта.

## PNG и Android Share

Рендер имеет фиксированный размер `1080 × 1350` и использует авторскую визуальную капсулу продукта. В кадре всегда присутствуют:

- бренд и отметка `18+`;
- афиша и один вопрос;
- исходная точка с региональным временем;
- физическая линия `тогда → пломба → сейчас`;
- честный итог;
- новая точка, предел паузы или время повторной проверки;
- две контрольные метки и информационный дисклеймер.

PNG сначала записывается во временный файл, затем атомарно переименовывается во внутреннем кэше. `AnalysisImageProvider` принимает только безопасное имя `.png`, проверяет canonical path, остается `exported=false` и открывает файл только для чтения. Выбранное пользователем приложение получает временный URI через стандартный Android Share. Разрешения Android и доступ ко всему накопителю не требуются.

## Приватность и ограничения

Создание кадра не меняет капсулу, нить, карту, оценки, паузу или выбранное событие. Постоянная запись и отдельная история экспортов не создаются. Во внутреннем кэше сохраняется только ограниченное число последних PNG; Android может удалить их в любое время.

Кадр отражает текущие локальные данные. Без лицензированного поставщика и аутентифицированного обновления он не подтверждает перенос матча, состав, старт, счет или финальный свисток.

## Проверяемые инварианты

- `SEALED` никогда не превращается в кадр;
- капсула и карта повторно проверяются непосредственно перед созданием снимка;
- `LIMIT_REACHED` не получает текущую строку и не заявляет достижение точки;
- новая точка существует только для `POINT_MOVED`, имеет тот же вид и строго более позднее время;
- снимок не удерживает полную карту, строку или результат капсулы;
- зона и время экспорта входят в SHA-256;
- имя файла ограничено безопасным ASCII-набором;
- PNG создается атомарно и передается только через read-only URI;
- экспорт не создает постоянное пользовательское состояние.
