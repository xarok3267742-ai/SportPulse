# «Карта нитей»

«Карта нитей» — общий read-only обзор всех вопросов, которые пользователь явно закрепил в «Нити события». Она возвращает личный контекст в ленту и показывает смысловые изменения между матчами без прогноза, коэффициентов, вероятности, награды или скрытого рейтинга.

## Источник данных

Карта перечисляет все ключи локальных нитей в закрытых `SharedPreferences`, а не только события активного фильтра или текущего Event Pack. Один момент `now` используется для всей агрегации.

Для нити текущего каталога приложение:

1. fail-closed читает сохраненную запись;
2. заново вычисляет текущий «Сюжет события»;
3. вычисляет переход `тогда → сейчас`;
4. строит текущий «Маяк события»;
5. выбирает ближайший момент, связанный с главой вопроса.

Если событие исчезло после замены Event Pack, исходная нить остается видимой, но текущий статус, афиша и время не придумываются.

## Состояния

- `TAMPERED` — запись не прошла SHA-256-проверку;
- `DETACHED` — валидная нить относится к событию вне текущего каталога;
- `MOVED` — состояние выбранной главы изменилось, но не завершилось;
- `MISSED` — предстартовая глава стала упущенной;
- `OPEN` — исходное состояние вопроса сохранилось;
- `RESOLVED` — выбранная глава завершена.

Шкала объединяет два первых состояния в шлюз «Связь», но строки и счетчики сохраняют точную причину. Остальные шлюзы: «Сдвиг», «Открыто», «Закрыто» и «Упущено».

## Открытый порядок

Сортировка полностью опубликована:

1. поврежденная запись;
2. событие вне каталога;
3. смысловой сдвиг;
4. упущенный момент;
5. открытый вопрос;
6. закрытый вопрос.

Внутри одного состояния раньше показывается ближайшая связанная временная точка, затем исходный порядок каталога и стабильный ID события. На экране видны первые четыре строки, а метрика и SHA-256 охватывают весь набор. Закладка, частота посещений, предполагаемый интерес, команда, турнир и вид спорта не меняют порядок.

## Связанный момент

Момент показывается только для `OPEN` и `MOVED`. Используется тот же контракт, что в панели нити и PNG-карточке:

- источник: окно проверки → срок факта → старт → разбор;
- факты: окно проверки → срок факта → старт;
- план: окно проверки → старт;
- решение и старт: указанный старт;
- разбор: открытие разбора.

Отсутствующий момент остается отсутствующим. Абсолютное время берется из текущего «Маяка» и форматируется в выбранной IANA-зоне.

## Целостность

Результат получает SHA-256-метку версии `sport-pulse-story-thread-map-v1`. Каноническая строка связывает для каждой отсортированной записи:

- ID и положение события в каталоге;
- отображаемую афишу, вид спорта и регион;
- состояние карты;
- пломбу исходной нити и метку текущего перехода;
- вид, время, действие и факторы ближайшего момента.

Строки кодируются с явной длиной, поэтому разделители в ID или афише не создают неоднозначность. Служебное время открытия экрана само по себе в метку не входит.

## Приватность и действия

Расчет не создает новую запись, историю просмотров, серию посещений, уведомление, задачу или фоновый сервис. Строка текущего события только открывает его read-only режим «Сюжет».

Для события вне каталога доступна явная команда удаления локальной нити. Во время «Режима тишины» она отключена в интерфейсе и повторно проверяется перед изменением состояния. Поврежденная нить текущего каталога очищается внутри события по существующему fail-closed сценарию.

## Тихое окно

Из полного результата карты приложение выводит одно read-only «Тихое окно». Среди строк `OPEN` и `MOVED` с будущим абсолютным моментом выбирается самая ранняя точка; при равном времени сохраняется опубликованный порядок карты. Состояния целостности, потерянные, закрытые и упущенные нити в выбор не входят.

Функция показывает, когда локальный сюжет может измениться не раньше доказанного момента, и не запускает обратный отсчет. Явная команда может активировать существующий глобальный режим тишины до этой точки в пределах 24 часов. Карта и окно повторно вычисляются перед подтверждением и перед записью. Полный контракт опубликован в [спецификации «Тихого окна»](story-quiet-window.md).

При активации выбранная строка, точка и метка карты входят в одну «Капсулу возврата». После срока текущая карта используется только для read-only сравнения выбранной нити; изменения других строк не превращаются в изменение вопроса. При создании [«Кадра возвращения»](story-return-frame.md) карта вычисляется еще раз, но в PNG не копируется: переносится только минимальное состояние выбранной связи. Правила опубликованы в [спецификации «Капсулы возврата»](story-return-capsule.md).

## Ограничения

Карта знает только локальный каталог и локальные состояния. Она не подтверждает перенос, отмену, состав, фактический старт или финальный свисток без лицензированного обновления. SHA-256 показывает детерминированность локального результата, но не является электронной подписью или доказательством внешнего времени.
