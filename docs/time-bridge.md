# Часовой мост СНГ

«Часовой мост СНГ» переводит время одного спортивного события из Москвы в выбранный город России или СНГ. Расчет выполняется локально через IANA time zone database устройства. Приложение не запрашивает геолокацию, сеть или системную часовую зону пользователя.

## Поддерживаемые зоны

| Город | IANA Zone ID |
| --- | --- |
| Москва | `Europe/Moscow` |
| Калининград | `Europe/Kaliningrad` |
| Екатеринбург | `Asia/Yekaterinburg` |
| Новосибирск | `Asia/Novosibirsk` |
| Владивосток | `Asia/Vladivostok` |
| Минск | `Europe/Minsk` |
| Астана | `Asia/Almaty` |
| Ташкент | `Asia/Tashkent` |
| Бишкек | `Asia/Bishkek` |
| Баку | `Asia/Baku` |
| Ереван | `Asia/Yerevan` |
| Тбилиси | `Asia/Tbilisi` |
| Душанбе | `Asia/Dushanbe` |

Смещения UTC не зашиты в приложение. `ZoneId` и правила смещения берутся из tzdata конкретного Android-устройства, поэтому применяются правила, известные его системе на дату события. Для Астаны используется опубликованная IANA-зона `Asia/Almaty`, представляющая единое время Казахстана в поддерживаемой tzdata.

## Источники времени

Для карточки действует строгий приоритет:

1. `startAt` из проверенного Event Pack: абсолютный Unix timestamp в миллисекундах переводится в точные локальные дату, день недели и время выбранного города.
2. `DemoSchedule` встроенного каталога: день недели и время заданы по Москве, затем переводятся в выбранную зону в пределах текущей московской недели. Карточка всегда сохраняет пометку «Демо».
3. Статическая подпись: если точного времени нет, приложение показывает исходное «по расписанию» и ничего не угадывает.

Изменение зоны влияет только на отображение. Исходный `startAt`, содержимое Event Pack и пользовательская аналитика не меняются.

## Граница даты

Для одного момента сравниваются локальные даты Москвы и выбранной зоны. Результат принимает одно из трех значений: `-1`, `0` или `+1` сутки. Панель показывает явную метку предыдущих, тех же или следующих суток. В карточке день недели и дата пересчитываются вместе со временем, поэтому, например, позднее московское событие может стать событием следующего дня во Владивостоке.

## Локальное состояние

Выбранная зона хранится в закрытых `SharedPreferences` как имя элемента `RegionalZone`. Неизвестное или поврежденное значение безопасно возвращает Москву. Простое открытие ленты с настройкой по умолчанию ничего не записывает.

Функция не использует:

- геолокацию;
- сетевой запрос;
- аккаунт;
- фоновый сервис;
- коэффициенты, прогнозы или результаты ставок.

## Контрольная метка

Панель строит SHA-256 по UTF-8 строке:

```text
sport-pulse-time-bridge-v1|zoneName|zoneId|evaluatedAtMinute|moscowOffsetSeconds|selectedOffsetSeconds|dayShift
```

`evaluatedAtMinute` равен Unix time в минутах. Метка фиксирует выбранную зону, системные смещения и переход даты в конкретную минуту. Это локальная проверка воспроизводимости расчета, а не электронная подпись и не подтверждение календаря события.

## Ограничения

- Качество перевода зависит от актуальности tzdata Android-устройства.
- Демо-расписание иллюстрирует механику продукта и не является официальным календарем.
- Точное время Event Pack достоверно только настолько, насколько достоверен поставщик файла; подпись подтверждает происхождение байтов, но не истинность спортивного факта.
- Приложение не определяет город автоматически: выбор всегда явный и локальный.
