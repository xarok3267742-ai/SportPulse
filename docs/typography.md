# Типографика

Типографика «Спорт Пульса» разделяет спортивное табло и спокойное чтение аналитики. Она не имитирует интерфейс букмекера и не использует типовой системный шрифт как визуальный голос продукта.

## Шрифты

- **Fira Sans Condensed Bold / SemiBold** — дисплейная гарнитура для заголовков, команд, фильтров, статусов и Canvas-графики. Узкие пропорции сохраняют плотность спортивного информационного экрана.
- **Golos Text Regular** — основная гарнитура для объяснений, методики, ограничений и длинных русскоязычных текстов.
- **System monospace** — только для контрольных отпечатков и технических значений, где важна форма строки.

Файлы находятся в `app/src/main/res/font` и загружаются через Android Resources. Интерфейс не обращается к CDN или сервису шрифтов.

## Масштабирование

- основной размер всегда следует системному `fontScale`;
- заголовки и команды переносятся без многоточия;
- фиксированные круглые маркеры ограничивают только собственный размер текста, а не масштаб содержимого;
- иллюстрированные заголовки увеличивают контейнер при 150% и 200%;
- при 200% горизонтальные фильтры остаются прокручиваемыми, а нижняя навигация сохраняет все пять разделов.
