## Что нового

- новый «Контроль данных» до разбора выдаёт один понятный вердикт по источнику, свежести и границе вывода;
- авторский image-заголовок связывает три физические станции: источник, часы свежести и стоп-границу; весь изменяемый текст остаётся нативным и адаптивным;
- API-провайдер, endpoint, лимит запросов и секреты скрыты даже из раскрытых технических деталей; остаются только время снимка, окно дат, число событий и безопасный тип канала;
- быстрый старт в «Инструментах» стал компактным, первое действие события остаётся целиком над навигацией, а навигатор подробного разбора прокручивается к новой View после смены раздела;
- unit-тесты, debug/release lint, серверные тесты `3/3` и полный device-прогон `19/19` при системном шрифте 100% и `19/19` при 200% прошли без ошибок.
