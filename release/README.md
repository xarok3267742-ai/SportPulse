## Что нового

- «Профиль проверки» теперь показывает цельный путь `решение → разбор → следующий навык`, а не независимые счётчики;
- процент замыкания считает только завершённые разборы того же SHA-256-снимка решения в доступном окне журнала; новая версия решения того же события не подменяет исходную;
- один адаптивный блок объединяет решения до матча, связанные разборы, покрытие, распределение статусов и конкретный следующий навык без ROI, коэффициентов и угаданных исходов;
- новый авторский image-цикл физически показывает капсулу решения, постсобытийную линзу и шкалу корректировки; весь смысловой текст остаётся нативным Android-контентом;
- метрики перестраиваются вертикально при крупном шрифте; unit-тесты, debug/release lint и полный device-прогон `20/20` при системном шрифте 100% и `20/20` при 200% прошли без ошибок.
