# Google Play Store Pack

Готовый комплект для основной русской карточки приложения «Спорт Пульс».

## Загрузка в Play Console

- `icon-512.png` — иконка карточки, 512 × 512.
- `feature-graphic-1024x500.png` — feature graphic, 1024 × 500.
- `screenshots/01-*.png` … `screenshots/06-*.png` — телефонные скриншоты, 1080 × 1920, в порядке показа.
- `listing-ru.md` — название, короткое и полное описание.
- `alt-text-ru.md` — альтернативный текст для графики.
- `preview/store-pack-overview.png` — обзор комплекта, не загружать как отдельный скриншот.
- `manifest.json` — размеры, режимы и происхождение графических экспортов.

Промо-фоны созданы через ImageGen. Логотип, русский текст, размеры и реальные UI-кадры собраны детерминированно скриптом `tools/build_store_assets.py`.
